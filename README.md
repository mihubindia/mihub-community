# Mewar Innovators Hub — Community Joining Form

A responsive, animated student community joining form for Mewar Innovators Hub.

## Included
- `index.html` — complete page
- `style.css` — responsive UI, MI Hub color palette, animations
- `script.js` — multi-step form, validation, mobile navbar, reveal animations and localStorage
- `assets/mi-hub-logo.png` — supplied header/hero logo
- `assets/mi-hub-footer-logo.png` — supplied footer logo

## Form sections
1. Basic Details
2. Secondary Education (10th): Board, Passing Year, Percentage
3. Senior Secondary Education (12th): Board, Passing Year, Percentage
4. Graduation: University/College, Degree, Branch, Current Year, Semester, Expected Graduation Year
5. Domain/Career Interest + Optional Skills + Optional reason for joining

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Important
This package is a frontend-only version. Submissions are saved to the browser's localStorage on that device. For real community registration, connect the submit handler to your backend/API and database.
